# Jogo de Adivinhação de Palavras

Projeto desenvolvido como atividade de encerramento da disciplina de **Desenvolvimento de Aplicações Web I** (IFPB — Campus Campina Grande).

## Integrantes
- Seu Nome Aqui

## Como jogar
1. Observe a **categoria** e a **dica** exibidas na tela.
2. Digite uma letra por vez no campo indicado e clique em **Tentar** (ou pressione `Enter`).
3. Cada letra correta é revelada na posição correspondente; cada erro reduz suas 6 tentativas.
4. Vença descobrindo a palavra completa antes que as tentativas acabem.

## Tecnologias
- HTML5 semântico
- CSS3 (Flexbox e layout responsivo)
- JavaScript (DOM, eventos, arrays e estruturas de repetição)

## Funcionalidades
- Sorteio aleatório de palavras com categorias e dicas
- Bloqueio de letras repetidas e caracteres inválidos
- Histórico de letras já utilizadas
- Placar de partidas, vitórias e derrotas
- Reinício rápido de partida
